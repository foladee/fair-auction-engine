# Fair Auction Engine

A reputation-weighted task auction system built on Stacks blockchain using Clarity smart contracts.

## Overview

Fair Auction Engine enables creators to post tasks with STX rewards and allows bidders to compete fairly based on reputation scores. The system ensures transparent winner selection and secure reward distribution.

## Features

- **Task Management**: Create tasks with STX rewards held in escrow
- **Reputation-Weighted Bidding**: Submit bids with reputation scores for fair competition
- **Secure Winner Selection**: Task creators select winners from qualified bidders
- **Reward Claims**: Winners claim rewards with finalization tracking
- **Access Control**: Admin and creator-based authorization
